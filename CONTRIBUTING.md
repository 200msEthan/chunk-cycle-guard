# Contributing

- `node --test` is the acceptance check. Every test passes, and the files under
  `test/` stay unchanged.
- No dependencies. The package has none, and the task needs none.
- Keep the change inside `src/`. Adding a file there is fine.
- Leave `.github/`, `package.json` and the fixtures alone.
- Plain ESM, Node 20 or newer. No build step and no TypeScript.
- By opening a pull request you agree to license your contribution under the
  MIT license in LICENSE.
